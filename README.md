# TFM – DS MARKET

![DS Market](img/dsmarket.png)

## 📊 Objetivo principal

Recrear un escenario de trabajo realista para un científico de datos, en el que los requerimientos están poco o nada definidos.  
En este caso, trabajamos para **DS MARKET**, una pequeña cadena de centros comerciales con 10 tiendas en 3 regiones de Estados Unidos.

El objetivo es analizar el comportamiento de ventas, segmentar productos y tiendas y construir un modelo predictivo que ayude a tomar decisiones de **abastecimiento y stock**.

## 📌 Tareas realizadas

- **Análisis de datos:** limpieza y preprocesamiento de más de **8 millones de registros** (enero 2011 – septiembre 2016), incluyendo creación de nuevas variables.
- **Clustering:** agrupación de productos y tiendas mediante técnicas no supervisadas para identificar patrones de comportamiento similares.
- **Predicción de ventas:** entrenamiento de modelos predictivos (XGBoost) para el mes de octubre, evaluando resultados con métricas como **RMSE y MSE**.
- **Abastecimiento:** propuesta de stock óptimo para todas las tiendas en base a las predicciones de ventas.
- **Visualización:** creación de un dashboard y una presentación final para la defensa del proyecto.
