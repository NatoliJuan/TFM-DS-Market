## 📊 Objetivo principal

Recrear un escenario de trabajo realista para un científico de datos, en el que los requerimientos están poco o nada definidos. En este caso, trabajamos para DS MARKET, una pequeña cadena de centros comerciales con 10 tiendas en 3 regiones de Estados Unidos.

## 📌 Tareas realizadas

• Análisis: limpieza y preprocesamiento de más de 8 millones de registros, con datos desde enero de 2011 hasta septiembre de 2016. Incluye creación de nuevas variables.  
• Clustering: agrupación de productos y tiendas mediante técnicas no supervisadas para identificar patrones de comportamiento similares.  
• Predicción de ventas: entrenamiento de modelos predictivos (XGBoost) para el mes de octubre. Evaluación mediante métricas como RMSE y MSE.  
• Abastecimiento: propuesta de stock óptimo para todas las tiendas en base a las predicciones.  
• Visualización: creación de un dashboard y presentación final para la defensa del proyecto.

## 🧠 Herramientas utilizadas

Python, pandas, scikit-learn, XGBoost, matplotlib, seaborn, Power BI, request, time.
